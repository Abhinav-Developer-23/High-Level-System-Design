Forward Flow: API Step-by-Step

Step System API / Action Logic Detail
1 TPAP Jobs Quartz Cron Trigger Fetches PENDING txns from Slave DB based on time window.
2 Kafka upi_jobs_primary_check_status Active topic carrying txnId and business type.
3 TPAP Consumers POST /upi/int/txn/status-jobs Dispatches task to TPAP Switch for internal processing.
4 TPAP Switch POST /upi/int/tpap/gateway/switch/v1/status Asynchronous call to OCIL Gateway using GatewayAsyncHttpClientHelper.
5 OCIL Gateway POST /upi/ext/txn/tsp/v1/transaction/status Transforms request to TSP-compatible format.
6 TSP Switch XML: ReqChkTxn/2.0 Final hop: Constructs NPCI XML and sends to external boundary.
