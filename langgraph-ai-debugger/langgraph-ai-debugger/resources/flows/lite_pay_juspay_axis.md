# Lite Pay Money (Juspay Axis) Flow

> Verified: 2026-04-27. APIs confirmed via Kibana (now-3d traffic).
> Systems: TPAP Switch | Juspay Axis Gateway | Juspay API

## Architecture Context
This flow describes a UPI Lite transaction initiated from the Paytm app using the **Juspay Axis** gateway. UPI Lite allows small-value transactions (up to ₹500) without a UPI PIN, using an **ARQC** (cryptogram) generated by the device's Common Library and a **LRN** (Lite Reference Number) to identify the on-device balance.

## Step-by-step: [Payer Side / TPAP]
1.  **Entry API:** `POST /upi/ext/txn/lite/v2/app-pay`
    *   **Controller:** `UPILiteController`
    *   **Service:** `LitePayService.requestPay`
    *   **DB Operations:**
        *   `INSERT INTO txn_info` (status=PENDING, txn_type=PAY, category=LITE)
        *   `INSERT INTO txn_participants` (payer and payee details)
    *   **Async Dispatch:** Calls `GatewayAsyncHttpClientHelper` to forward request to Juspay Gateway.
2.  **Callback Handling:** `POST /upi/int/txn/issuing/txn-callback`
    *   **Controller:** `TPAPGatewayController.tpapGatewayCallback`
    *   **Service:** `PSPGatewayTxnUpdateService.pspGatewayUpdateTxnDetails`
    *   **DB Operations:**
        *   `UPDATE txn_info` (status=SUCCESS/FAILURE, npci_resp_code, rrn)

## Step-by-step: [Gateway / Juspay Axis]
1.  **Entry API:** `POST /upi/int/tpap/gateway/transaction/v1/lite/send-money`
    *   **Controller:** `TransactionController.SendMoneyLite`
    *   **Logic:** Uses `liteRequestMapper` to transform `NPCIInTO` (Switch DTO) into `LiteRequest` (Juspay SDK DTO).
    *   **Payload:** Includes `arqccred` (device cryptogram) and `lrn` (Lite Reference Number).
2.  **Downstream Call:** `POST /api/p2/merchants/transactions/sendMoney`
    *   **Client:** `LiteRequestAPIClient`
    *   **Destination:** Juspay SDK (`upisdk.axis.bank.in`)
3.  **Callback Response:** After Juspay processes the transaction with NPCI, it returns the result to the gateway, which then invokes the TPAP Switch callback.

## NPCI API: ReqPay (Lite)
The `ReqPay` API for UPI Lite differs from standard Pay in the following ways:
*   **Cred Type:** `ARQC` (Authorization Request Cryptogram) - replaces the PIN.
*   **Cred Subtype:** `Initial`.
*   **Detail Name:** `LRN` (Lite Reference Number).
*   **Purpose:** `44` (or 41-43) specifically for UPI Lite.
*   **Initiation Mode:** `17` (On-device wallet).
